# ADR-0003：全向感知仲裁——海康优先、USB 锁相机与方位保持

- **状态**：Accepted
- **日期**：2026-11-03
- **相关代码**：`src/omni/decider.cpp`、`src/omni/perceptron.cpp`、`apps/omni_standard.cpp`

## 背景

3 路 USB 相机固定在大 yaw 上（安装角 −30° / +30° / 180°），海康相机在小 yaw 上；
大小 yaw 的分配由电控完成。USB 链路默认使用 YOLO（与海康同模型）做检测，但不做 PnP，
不能得到可靠的米制距离；识别结果只用于显示，不参与选目标。
海康 FOV 54.2°，USB FOV 37°；后置 180° 目标在转向海康的过程中会经过约 113° 的无覆盖盲区。

## 决策

1. 海康 tracker 有目标时绝对优先；连续空 `omni_hik_lost_s`（默认 0.3 s）才回退 USB。
2. 回退时按 `size_score = 装甲像素宽 / 图像宽` 选“最近”的一路 USB，并**锁定相机**；
   锁定期间不比较其他相机，也不切换目标。
3. 锁定相机超过 `omni_usb_max_age_s`（0.15 s）无新结果时进入 **coast**：
   继续朝最后已知的**目标绝对方位**转动，不切换、不外推。
4. 海康出现目标立即接管；coast 超过 `omni_guide_coast_s`（1.5 s）仍未接管则停止，
   冷却 `omni_guide_cooldown_s`（0.5 s）后重新选最近目标。
5. 锁定与 coast 都发送 `mode=1`、`is_empty=false`；只有无锁定且不在 coast 时才发 `mode=0`。
6. 血量档位（`hp_level`）是发给雷达的独立输出，不参与仲裁。

## 被否方案

- **每帧比较三路 USB 距离**：两目标距离接近时会在相机间反复切换，限速/低通只能减慢、不能消除。
- **用 PnP 米制距离**：USB 链路未 solve，且 `camera_matrix` 与 USB 分辨率/FOV 不匹配。
- **锁定相机丢失即停**：后置 180° 目标会在 113° 盲区前丢失，云台停住后永远到不了海康视场。
- **coast 时外推目标角速度**：增加新的抖动源；1.5 s 内最后方位通常仍落在海康 FOV 附近。

## 影响

- 锁定期间会忽略其他相机中更近的目标；这是用稳定性换最优性。
- `size_score` 是距离代理，不是米；不同装甲类型会造成偏差，需上机验证。
- 依赖 `VisionToGimbal.yaw` 为世界系绝对方位；若协议改成增量，本决策需重审。
- 几何换算假设引导期间**小 yaw 保持 0°**（USB 世界轴 = 海康世界 yaw + 安装角）；
  若电控会让小 yaw 偏转且反馈里拿不到该角度，USB 方位会带上同等偏差。
