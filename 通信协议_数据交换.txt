本工程与电控之间存在两套通信链路，请按车型选用:

  1. 串口协议 (Gimbal 类)   —— 步兵/英雄等标准车 (configs/standard1.yaml)
  2. CAN 协议  (CBoard 类)  —— 哨兵/无人机 (configs/demo.yaml 等)


一、串口协议 (Gimbal) —— 步兵/标准车

参数:
  - 串口:  /dev/ttyACM0 (以配置文件 com_port 为准)
  - 波特率: 115200
  - 数据位: 8, 校验: none, 停止位: 1
  - 字节序: 小端 (Little Endian), float 为 IEEE754
  - 结构体均 __attribute__((packed)) 紧凑排列无填充
  - 帧格式: 帧头 'S' 'P' + 数据 + CRC16

CRC16 说明:
  - 多项式 0x1021 (查表右移实现, 反射多项式 0x8408)
  - 初值 0xFFFF
  - 校验范围: 从帧头 'S' 起, 到 crc16 字段之前 (不含 crc16 字段)
  - crc16 字段存储为小端 (低字节在前)

--------------------------------------------------------------
1.1 电控 -> 视觉  (GimbalToVision, 共 29 字节)
--------------------------------------------------------------
偏移  类型      名称            含义
0     uint8[2]  head            帧头 {'S','P'}
2     uint8     mode            模式: 0=空闲 1=自瞄 2=小符 3=大符
3     float     yaw             云台当前 yaw 角 (rad)
7     float     yaw_vel         云台 yaw 角速度 (rad/s)
11    float     pitch           云台当前 pitch 角 (rad)
15    float     pitch_vel       云台 pitch 角速度 (rad/s)
19    float     bullet_speed    子弹速度 (m/s), 用于弹道补偿
23    int       id              机器人/云台 ID
27    uint16    crc16           CRC16 校验 (小端)

--------------------------------------------------------------
1.2 视觉 -> 电控  (VisionToGimbal, 共 31 字节)
--------------------------------------------------------------
偏移  类型      名称            含义
0     uint8[2]  head            帧头 {'S','P'}
2     uint8     mode            0=不控制 1=控制云台但不开火 2=控制云台且开火
3     float     yaw             目标 yaw 角 (rad)
7     float     yaw_vel         目标 yaw 角速度 (rad/s)
11    float     yaw_acc         目标 yaw 角加速度 (rad/s^2)
15    float     pitch           目标 pitch 角 (rad)
19    float     pitch_vel       目标 pitch 角速度 (rad/s)
23    float     pitch_acc       目标 pitch 角加速度 (rad/s^2)
27    bool      shoot           是否开火
28    bool      is_empty        目标是否为空 (丢失目标时置 true)
29    uint16    crc16           CRC16 校验 (小端)

说明: mode 与 shoot 的对应关系为
        mode = control ? (fire ? 2 : 1) : 0

二、CAN 协议 (CBoard) —— 哨兵/无人机
================================================================
参数:
  - 接口: can0 (以配置文件 can_interface 为准)
  - 帧: 标准帧, DLC = 8
  - 多字节整数统一 大端 (高字节在前)
  - CAN ID 以配置文件为准, 示例 (demo.yaml):
        quaternion_canid   = 0x100   (电控发: 姿态四元数)
        bullet_speed_canid = 0x101   (电控发: 弹速/模式)
        send_canid         = 0xff    (视觉发: 控制指令)

--------------------------------------------------------------
2.1 电控 -> 视觉: 四元数帧 (ID = quaternion_canid)
--------------------------------------------------------------
字节     名称      含义
0-1     x         int16, 四元数 x / 1e4
2-3     y         int16, 四元数 y / 1e4
4-5     z         int16, 四元数 z / 1e4
6-7     w         int16, 四元数 w / 1e4

--------------------------------------------------------------
2.2 电控 -> 视觉: 状态帧 (ID = bullet_speed_canid)
--------------------------------------------------------------
字节     名称          含义
0-1     bullet_speed  int16 / 1e2, 子弹速度 (m/s)
2       mode          模式: 0=idle 1=auto_aim 2=small_buff 3=big_buff 4=outpost
3       shoot_mode    射击模式(哨兵): 0=left_shoot 1=right_shoot 2=both_shoot
4-5     ft_angle      int16 / 1e4, 无人机专有角度 (rad)
6-7     保留

--------------------------------------------------------------
2.3 视觉 -> 电控: 控制指令帧 (ID = send_canid)
--------------------------------------------------------------
字节     名称              含义
0       control           是否接管控制 (0/1)
1       shoot             是否开火 (0/1)
2-3     yaw               int16 / 1e4, 目标 yaw 角 (rad), 大端
4-5     pitch             int16 / 1e4, 目标 pitch 角 (rad), 大端
6-7     horizon_distance  int16 / 1e4, 无人机水平距离 (m), 大端

================================================================
三、注意事项
================================================================
1. 角度单位统一为 弧度 (rad), 打印/调试时 ×57.3 转度。
2. 串口协议 float 为小端 IEEE754; CAN 协议 int16 为大端。
3. 串口帧校验失败会被视觉端丢弃 (CRC16 不匹配)。
4. 若使用模拟模式 (配置 simulate: true), 视觉不打开串口,
   仅打印模拟下发数据, 便于无硬件联调。
